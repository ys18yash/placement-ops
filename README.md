# PlacementOps

Constraint-Aware Placement Scheduling & Real-Time Replanning Platform

## Overview

PlacementOps is a placement-week scheduling system designed to generate
feasible interview schedules and replan them when real-world disruptions
occur.

## Problem

A placement week involves multiple companies, students, interview panels,
rooms, overlapping shortlists, and unexpected disruptions.

The system aims to:

- Generate realistic placement data
- Generate feasible interview schedules
- Detect scheduling conflicts
- Replan schedules after disruptions
- Minimize unnecessary schedule changes
- Explain scheduling decisions
- Provide a coordinator-focused dashboard
- Measure schedule quality and replanning performance
